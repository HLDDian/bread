# YOLOv8 實例分割操作指南 (do.md)

本文件整理了從標註資料轉換、資料集劃分、模型訓練到模型預測的完整執行流程與參數說明。

---

## 步驟 1. 轉出 YOLO 資料集 (Labelme 轉換)

使用 `labelme2yolo` 工具將 Labelme 產生的標註 JSON 格式轉換為 YOLOv8 實例分割所需的標籤格式（正規化多邊形坐標）。

### 執行指令

```bash
labelme2yolo --json_dir dataset --val_size 0.2 --test_size 0.1 --output_format polygon --output_dir YOLODataset
```

### 參數詳細說明

| 參數名稱            | 設定值          | 用途說明                                                                                                                                         |
| :------------------ | :-------------- | :----------------------------------------------------------------------------------------------------------------------------------------------- |
| `--json_dir`      | `dataset`     | **標註來源目錄**：包含 Labelme 標註產生的 `.json` 檔與原始影像之資料夾路徑。                                                             |
| `--val_size`      | `0.2`         | **驗證集比例**：將總資料量的 20%（0.2）劃分為驗證集（Validation Set），用來在訓練過程中評估模型泛化能力與調整超參數。                      |
| `--test_size`     | `0.1`         | **測試集比例**：將總資料量的 10%（0.1）劃分為測試集（Test Set），作為最終不參與訓練的獨立測試資料（其餘 70% 則自動劃為訓練集 Train Set）。 |
| `--output_format` | `polygon`     | **輸出標註格式**：設定為 `polygon`（多邊形點坐標），專用於「實例分割（Instance Segmentation）」任務。若為目標檢測則通常為 `bbox`。     |
| `--output_dir`    | `YOLODataset` | **輸出目錄名稱**：轉換後的 YOLO 格式資料集（含 `images`、`labels` 與 `dataset.yaml`）所要儲存的目標資料夾路徑。                      |

---

## 步驟 2. 手動調整與確認資料集劃分

自動依比例隨機切分可能因樣本數較少或類別分佈不均，需依實際需求手動調整圖片與標籤數量。

### 說明與檢查項目

- **手動配置範例**：
  - 驗證集（`val`）：4、6 
  - 測試集（`test`）：5
  - 訓練集（`train`）：其餘照片
- **操作注意事項**：
  - 移動圖片（`YOLODataset/images/{train|val|test}`）時，必須將對應同檔名的標籤檔（`YOLODataset/labels/{train|val|test}/*.txt`）一併移動，維持一一對應關係。
  - 確認 `YOLODataset/dataset.yaml` 中的各集合路徑以及類別數量與名稱正確。

## 步驟 3. 實例分割模型訓練

使用 Ultralytics YOLOv8 啟動實例分割模型訓練任務。

### 執行指令

```bash
yolo segment train data=YOLODataset/dataset.yaml model=yolov8n-seg.pt epochs=200 imgsz=640 batch=8 device=cpu
```

### 參數詳細說明

| 參數名稱    | 設定值                       | 用途說明                                                                                                                                    |
| :---------- | :--------------------------- | :------------------------------------------------------------------------------------------------------------------------------------------ |
| `segment` | *(子命令)*                 | **任務類別**：指定為實例分割（Instance Segmentation）任務。                                                                           |
| `train`   | *(模式)*                   | **執行模式**：指定執行模型訓練模式。                                                                                                  |
| `data`    | `YOLODataset/dataset.yaml` | **資料集配置檔**：指向定義類別名稱（names）、類別數（nc）以及 train/val/test 影像路徑的 YAML 檔案。                                   |
| `model`   | `yolov8n-seg.pt`           | **骨幹模型權重**：使用預訓練的 Nano 版本分割模型權重（`yolov8n-seg.pt`），體積小、推論快速，適合入門與輕量推論設備。                |
| `epochs`  | `200`                      | **訓練週期數（輪數）**：整份訓練資料集被完整學習遍歷的次數。若模型收斂且指標持續未改善，內建的 Early Stopping（早停機制）會提前終止。 |
| `imgsz`   | `640`                      | **輸入影像解析度**：模型訓練時統一將影像縮放為 640×640 像素進行運算與特徵提取。                                                      |
| `batch`   | `8`                        | **批次大小（Batch Size）**：每次權重梯度更新前同時計算的圖片數量。數值越大記憶體佔用越高；若發生記憶體不足（OOM），可下調為 `4`。   |
| `device`  | `cpu`                      | **運算裝置**：指定訓練運算的硬體。`cpu` 代表使用處理器；若具備 NVIDIA 顯卡並已配置 CUDA，可改為 `device=0` 以顯著加速訓練。       |

## 步驟 4. 模型預測與推論

利用訓練完成的最佳模型權重，對測試圖片或資料夾進行推論並輸出分割遮罩結果。

### 執行指令

```bash
yolo segment predict model=runs/segment/train/weights/best.pt source=test.jpg conf=0.25 save=True
```

> **提示**：專案內亦提供自訂預測腳本，可執行 `python predict.py`，它會自動抓取最新一次訓練產生的 `best.pt` 進行預測。

### 參數詳細說明

| 參數名稱    | 設定值                                 | 用途說明                                                                                                                                           |
| :---------- | :------------------------------------- | :------------------------------------------------------------------------------------------------------------------------------------------------- |
| `segment` | *(子命令)*                           | **任務類別**：指定為實例分割（Instance Segmentation）任務。                                                                                  |
| `predict` | *(模式)*                             | **執行模式**：指定執行預測推論模式。                                                                                                         |
| `model`   | `runs/segment/train/weights/best.pt` | **模型權重路徑**：載入訓練時在驗證集上 mAP 評分最佳的權重檔案（`best.pt`）。                                                               |
| `source`  | `test.jpg`                           | **推論來源目標**：待預測的目標，可以是單張圖片路徑（如 `test.jpg`）、圖片資料夾路徑、影片檔或攝影機編號（如 `0`）。                      |
| `conf`    | `0.25`                               | **信心度門檻（Confidence Threshold）**：只保留模型預測信心分數大於等於 0.25（25%）的偵測結果，過低的值會保留較多雜訊，過高的值可能導致漏檢。 |
| `save`    | `True`                               | **儲存預測成果**：設為 `True` 會將帶有分割遮罩（Mask）、邊界框與標籤名稱的成果圖片儲存到 `runs/segment/predict/` 目錄中。                |
